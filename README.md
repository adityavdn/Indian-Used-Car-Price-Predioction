# 🚗 Indian Used Car Price Prediction

![Python](https://img.shields.io/badge/Python-3.8+-blue.svg)
![Automotive](https://img.shields.io/badge/Automotive-Pricing-blue.svg)

## 📖 Overview

Regression model to predict used car prices in the Indian market based on brand, model, year, fuel type, transmission, mileage, and condition. Assists buyers and sellers in fair pricing.

## 🎯 Features

- Price prediction for used cars
- Brand and model analysis
- Depreciation patterns
- Market trend insights

## 🛠️ Tech Stack

- Scikit-learn, XGBoost
- Pandas, NumPy
- Matplotlib, Seaborn

## 🚀 Usage

```bash
git clone https://github.com/adityavdn/Indian-Used-Car-Price-Predioction.git
pip install -r requirements.txt
jupyter notebook
```

## 📊 Price Factors

- Make, Model, Year
- Kilometers Driven
- Fuel Type, Transmission
- Owner Type, Location
